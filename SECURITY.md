# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's GitHub security advisory workflow or contact the maintainers
through the private contact listed on the GitHub profile.

Include the affected version, reproduction steps, impact, and a suggested
mitigation when possible. Do not include secrets, tokens, or private user data.

Supported security fixes target the latest release line. Consumers should keep
NestJS, Colyseus, transport, and Redis adapter versions aligned with the
compatibility table in the README.
